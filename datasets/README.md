# 20 Newsgroups dataset

This directory hosts an unchanged copy of the original 20 Newsgroups archive for CS6350 Assignment 2. The archive contains message files grouped by newsgroup label.

Dataset assembled by Ken Lang and distributed through the CMU Text Learning Group Data Archives.

Original description: https://www.cs.cmu.edu/afs/cs.cmu.edu/project/theo-20/www/data/news20.html

Original archive: https://www.cs.cmu.edu/afs/cs.cmu.edu/project/theo-20/www/data/news20.tar.gz

The assignment program downloads this archive and performs preprocessing during execution.
